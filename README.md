## 🌐 About DuRT

**DuRT** (Du Real-time Transcriber) is an all-in-one native macOS application designed for high-performance audio speech recognition, subtitle styling, AI transcription refinement, and automated multi-channel delivery.

Whether for cross-border conference interpretation, video subtitle burning, academic lecture archiving, or podcast summarization, DuRT combines native Apple Silicon neural acceleration with cloud LLM workflows to deliver a seamless, privacy-first transcription workstation.

---

## ⚡ Key Features

- 🚀 **Zero-Latency Streaming & Offline Apple ASR**: Deeply integrated with Apple Silicon Neural Engine (ANE) and Apple Speech framework. Transcribe completely offline with zero network latency and zero privacy risk. Supports aggregated engines like OneASR, Whisper, and Paraformer.
- 🔄 **Modular Workflow Pipeline Automation**: Seamlessly pipe from Audio Capture (Mic / System Internal Audio via ScreenCaptureKit) ➔ Custom Glossary Normalization ➔ Real-time / Full Translation ➔ AI Content Distillation ➔ Text-to-Speech (TTS) ➔ Multi-channel Delivery.
- 🎬 **Studio-Grade Subtitle Canvas**: Interactive timeline with 2D absolute positioning, filler word removal, bilingual split tracks, customizable typography, and multi-format export (SRT, VTT, TXT, and burned-in MP4 video).
- 🤖 **1:1 Task-Dedicated AI Copilot**: Every transcription task gets an isolated, dedicated AI conversational partner equipped with instant action tiles (Executive Summary, Action Items, Key Takeaways, Q&A).
- 📦 **Automated Multi-Channel Delivery**: Directly deliver notes and media to Local Folders, Obsidian Vaults, Amazon S3, WebDAV servers, Notion databases, or custom Webhooks.
- 🔒 **Privacy-First Native Architecture**: Crafted in pure Swift and SwiftUI. All databases and transcripts are encrypted and stored locally with GRDB.
